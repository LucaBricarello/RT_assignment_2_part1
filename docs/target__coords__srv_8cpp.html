Detailed Description

Service node for retrieving the last target coordinates.

Author
Luca Bricarello
Version
1.1
Date
09/03/2025

Subscribes to:

  • /targ_coords

Services:

  • /get_last_target

Description:
This node provides a service that returns the last target coordinates received. It subscribes to the /targ_coords topic to update the last known target position and responds to service calls with the last recorded coordinates.
